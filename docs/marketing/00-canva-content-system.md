# Sistema de Contenido y Canva — Always Beautiful

## 1. Propósito del documento

Este documento define el sistema inicial de marketing, contenido y producción visual para Always Beautiful usando Canva como herramienta principal.

El objetivo es transformar Canva en una herramienta integrada al proceso de producto, no usarlo solo como diseño aislado.

Codex podrá apoyar con planificación, copies, briefs, guiones, calendarios, naming de assets y documentación de campañas.

---

## 2. Principio central

Canva se usará inicialmente de forma manual y estratégica.

Canva Connect API queda para una fase futura.

Codex no debe asumir que puede editar Canva directamente si no existe integración configurada.

---

## 3. Diferencia con documentación previa

Antes de esta fase, el proyecto tenía una visión de Storefront, Dashboard y operación interna.

Este documento agrega una capa comercial: cómo producir contenido, cómo nombrarlo, cómo planificar campañas y cómo conectar marketing con Storefront, Dashboard e IA futura.

## 7. Sistema de campañas

Cada campaña debe documentar:

1. Nombre de campaña.
2. Objetivo.
3. Público.
4. Servicio o producto principal.
5. Mensaje central.
6. CTA.
7. Canal.
8. Formato.
9. Fecha.
10. Assets requeridos.
11. Copy.
12. Estado.

---

## 8. Naming de campañas

Formato recomendado:

```text
YYYY-MM-canal-objetivo-tema
```

Ejemplos:

```text
2026-05-instagram-captacion-hidratacion-capilar
2026-05-whatsapp-recordatorio-reservas
2026-06-storefront-lanzamiento-productos
```

---

## 9. Naming de assets

Formato recomendado:

```text
canal_tipo_fecha_tema_version
```

Ejemplos:

## 11. Sistema de copies

Cada copy debe incluir:

- Hook inicial.
- Mensaje principal.
- Beneficio.
- CTA.
- Hashtags si aplica.
- Variante corta.
- Variante larga.

Ejemplo:

```text
Hook:
Tu cabello también necesita una pausa.

Mensaje:
Agenda una hidratación profesional y recupera suavidad, brillo y movimiento.

CTA:
Reserva tu hora.

Variante corta:
Hidratación capilar profesional. Reserva tu hora.

Variante larga:
Dale a tu cabello un cuidado más completo con una atención profesional pensada para recuperar suavidad y brillo. Consulta disponibilidad y agenda tu hora.
```

---

## 12. Guiones para reels

Formato recomendado:

```text
Duración:
Objetivo:
Escena 1:
Escena 2:
Escena 3:
Texto en pantalla:
Música sugerida:
Transición:
CTA final:
```

Ejemplo:

```text
Duración:
15 segundos

Objetivo:
Promover servicio de hidratación capilar.

Escena 1:
Plano detalle del cabello antes de la atención.

Escena 2:
Proceso visual del tratamiento.

Escena 3:
Resultado final con brillo y movimiento.

Texto en pantalla:
Tu cabello merece cuidado profesional.

CTA final:
Reserva tu hora.
```

## 15. Relación con IA

La IA futura puede apoyar marketing mediante:

- Generación de copies.
- Variantes de mensajes.
- Resumen de campañas.
- Recomendaciones de promoción.
- Segmentación básica.
- Sugerencias de calendario.

Codex puede preparar drafts, pero el usuario debe revisar tono, exactitud y coherencia comercial.

---

## 16. Canva Connect API futura

### Objetivo

Evaluar automatización o integración con Canva cuando el sistema manual esté maduro.

### Posibles usos

- Crear briefs estructurados.
- Organizar assets.
- Sincronizar piezas.
- Generar plantillas.
- Documentar campañas.
- Vincular assets con Storefront.

### Reglas

- No integrar API sin documentación oficial.
- No conectar cuenta real sin aprobación.
- No automatizar publicación sin revisión.
- No modificar campañas activas sin autorización.

---

## 19. Reglas de tono

El tono de Always Beautiful debe ser:

- Profesional.
- Elegante.
- Cercano.
- Confiable.
- Premium.
- Claro.
- No exagerado.

Evitar:

- Promesas irreales.
- Lenguaje médico no validado.
- Exceso de descuentos.
- Mensajes poco profesionales.
- Textos genéricos sin identidad.

---

## 20. Orden recomendado de implementación

1. Documentar sistema de campañas.
2. Definir calendario editorial.
3. Crear naming de assets.
4. Crear briefs para Canva.
5. Crear copies base.
6. Crear plantillas manuales.
7. Usar assets en Storefront.
8. Medir campañas.
9. Evaluar Canva Connect API.

---

## 21. Regla final

Canva debe integrarse al sistema de negocio como una capa de producción visual y marketing, no como una herramienta aislada.

Codex puede ayudar a estructurar la producción, pero la revisión visual y estratégica final corresponde al usuario.
